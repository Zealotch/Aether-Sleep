POWER TIMER - Aether Sleep Desktop Edition
=========================================

1. Cara Menggunakan:
   Cukup klik dua kali file 'PowerTimerWeb.exe'. Anda tidak perlu menginstal apapun.

2. Apa itu Power Timer?
   Aplikasi pintar untuk menjadwalkan komputer Anda Hibernate \ Shutdown otomatis. Sangat cocok bagi Anda yang sering ketiduran saat   mendownload file besar atau mendengarkan musik pengantar tidur.

3. Fitur Keamanan:
   Aplikasi ini sangat aman dan menggunakan Windows Task Scheduler bawaan. Jika Anda menekan tombol Start, Anda bahkan bisa langsung menutup aplikasinya (X) dan komputer akan tetap tertidur sesuai jadwal!

Selamat menggunakan!
